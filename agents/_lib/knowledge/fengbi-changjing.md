# 封闭场景（暴风雪山庄）的结构设计
tags: 封闭场景, 经典结构, 暴风雪山庄, 孤岛

---
封闭场景的价值在于"物理上逃不掉"，因此玩家不会浪费时间怀疑外部人员。这一点必须在开场 10 分钟内确立，否则整个推理逻辑会漏气。

## 封闭的必要条件（缺一不可）
1. **交通中断的具体理由**：暴雪封路、桥塌、船毁、通讯中断。要具体到"什么时间断的"，因为这个时间点本身可以成为时间锚。
2. **人数固定且可数**：明确列出在场人员，最好有一个"点名"场景（晚宴、集合、合影）。
3. **外部救援的时间预期**：什么时候会有人来？这个预期决定玩家的紧迫感。
4. **空间边界清晰**：建筑平面图要公开，玩家能自己在地图上走一遍。

## 经典选址与对应细节

| 场景 | 天然优势 | 环境细节可用的线索 |
| --- | --- | --- |
| 雪山山庄 | 脚印必留、声音被雪吸收 | 雪地脚印、融雪时间、壁炉燃烧时长 |
| 孤岛别墅 | 潮汐限制行动、无外部通讯 | 潮汐时间表、船的状况、海水浸泡痕迹 |
| 远洋游轮 | 房间密集、监控盲区明确 | 甲板监控死角、航向记录、舱室钥匙 |
| 古宅/城堡 | 密道、老式机关合理 | 建筑图纸、封死的门、地窖温度 |
| 深山民宿 | 老板与客人关系紧密 | 登记簿、钥匙牌、厨房库存 |

## 多人死亡的处理
- **不超过 3 起死亡**：再多会让玩家的注意力从推理转向追命。
- **每起死亡必须推进认知**：第二起死亡应推翻第一起建立的某个假设，而不是单纯增加恐怖感。
- **死亡顺序有意义**：凶手杀人的顺序应与其动机逻辑一致（先灭口最危险的、再处理最亲近的）。

## 公平性要点
1. 平面图、人员名单、时间表必须在第一轮公开。
2. 每个角色都要有"离开公共视野"的时间段，否则凶手无处作案、玩家无从推理。
3. 关键线索不能只存在于"某人独自发现的现场"，必须有第二人可验证（哪怕是间接的：听到声音、看到灯亮）。
4. 红鲱鱼（误导线索）2~4 个，且每一个都应该能被现有线索排除——不能靠"作者没写"来排除。

## 常见失败模式
- **封闭是假的**：中途冒出外部人员或未提及的房间。
- **全员都有秘密，但秘密与案件无关**：浪费玩家推理资源。每个角色的秘密最好与案件有间接关联（提供动机或误导）。
- **凶手是唯一没有秘密的人**：这本身就是最大的破绽，容易被老玩家一眼锁定。
- **环境细节不参与推理**：雪、潮汐、风声只当氛围用，玩家会觉得浪费设定。
