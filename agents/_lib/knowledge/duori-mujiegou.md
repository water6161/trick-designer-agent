# 多日多幕结构的时间设计
tags: 多日, 幕结构, 时间线, 节奏, 结构

---
跨多日的剧本（旅行团、训练营、家族聚会）最容易把时间线写崩，因为"日期 × 幕 × 角色自由度"是乘法关系。

设计要点：
1. 用"天 → 幕 → 场"三级结构，每天最多 3 幕。玩家记时间线靠的是"第一天晚宴、第二天寻宝"这种事件锚点，不是 21:47 这种精确分钟——跨日剧把分钟级精度留给案发当晚就够了。
2. 案发前的日子写"关系演变"（谁和谁结盟、谁被孤立），案发当日写"行动轨迹"。两类内容不要混在一张表里，玩家读起来会迷失。
3. 多日结构里"宵禁/集合点"是行动边界：每晚 22:30 清点人数，凶手离开过就要在清点里留矛盾——这是天然的查证抓手。
4. 日期切换用明显的格式分隔（## 第二天），不要让 DM 靠翻页猜"现在是第几天"。

雷区：
- 白天的自由活动写得太开放（"各自行动两小时"），等于宣布这期间什么都可能发生，时间线直接失控。收窄为"三个可选地点 + 在场证人"。
- 天气只装饰不参与：跨日剧的天气（暴雨断路、高温）应该影响当日行动边界，否则别写。
