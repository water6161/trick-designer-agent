# 搜证轮次与圆桌讨论的节奏设计
tags: 搜证, 轮次, 圆桌, 节奏, DM, 流程

---
搜证轮次的本质是"信息释放的阀门"。开一轮、放多少、藏多深，直接决定推理质量。

轮次设计原则：
1. **两轮搜证 + 每轮限拿 N 张**比"随便搜"好得多：限量制造选择压力（拿 C7 还是 C3？），玩家会为取舍争论——争论本身就是沉浸。
2. 第一轮给"事实层"（尸体状况、房间布置），第二轮给"关系层"（日记、聊天记录）。顺序反了玩家会先入为主。
3. 关键证据（能直接锁凶的）必须拆成两半分别藏在两轮，或需要两条线索交叉才成立——防止一次搜证就终局。
4. 公开讨论用"陈述 → 质询 → 表决"三段式：每轮每人先陈述一段，再开放质询，最后表决进入下一轮。没有结构的自由讨论必然被话多的玩家填满。

DM 控场点：
- 某轮全员沉默超 2 分钟，就"激活"一条沉睡线索（NPC 来访、广播响起）。
- 搜证时给地点菜单（书房/厨房/码头），报出的地点是公共信息——谁优先搜了哪里，本身就是行为线索。
