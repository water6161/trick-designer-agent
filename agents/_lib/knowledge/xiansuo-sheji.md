# 线索清单的结构与分配
tags: 线索设计, 经典结构, 公平性

---
线索表的组织方式直接决定推理体验。好的线索表让玩家"每条都有用，每条都能查"，坏的线索表让玩家"看了等于没看"。

## 三条硬指标
1. **总量 12~20 条**：公开 6~10，深入 6~10。
2. **每条线索必须写明四件事**：指向谁 / 排除谁 / 玩家如何获得 / 为什么公平（即为什么这条线索不可能被凶手藏起来）。
3. **至少 2 条独立公开线索 + 1 条深入线索构成锁凶证据链**，且动机、机会、手法三要素都要有线索覆盖。

## 线索的五个功能分类

| 功能 | 数量建议 | 作用 |
| --- | --- | --- |
| 时间锚点 | 3~4 条 | 建立可交叉验证的时间轴 |
| 手法证据 | 3~5 条 | 支撑核心诡计的每一步 |
| 人物秘密 | 3~5 条 | 提供动机与红鲱鱼 |
| 排除线索 | 2~4 条 | 用于排除无辜者 |
| 环境/氛围 | 2~3 条 | 强化场景、可暗藏细节 |

## 公开与深入的分配
- **公开线索**：搜证即可获得，所有人共享。用于建立基础认知和第一轮讨论。
- **深入线索**：需要条件触发（特定地点、特定人、特定提问），用于第二轮推进。
- **分配原则**：真相所需的最后一环必须在深入线索里，但不能只有凶手一人能获得。

## 常见错误

1. **万能线索**："一把带血的刀"既指向 A 又指向 B，等于什么都不指向。每条线索应有明确指向。
2. **无用线索**："桌上有一束花"——除非花的花期能证明时间，否则删掉。
3. **只增不减**：所有线索都指向凶手，玩家第一轮就锁定了，后面两小时没得推。
4. **线索全靠自白**：关键信息只能从某角色口中问出，等于把推理变成了盘问。
5. **数量过多**：超过 24 条，玩家会放弃整理，转为随机猜测。

## 公平性自查问题清单
- 如果没有凶手角色的剧本，玩家能否通过公开线索推出凶手？
- 凶手能否通过隐藏某条线索来逃脱？（若能，该线索就不公平）
- 每条指向凶手的线索，是否可以从至少两个角度被验证？
- 排除其他角色时，是否每个都用到了独立的线索？
- 红鲱鱼是否都有明确的排除线索，而不是"作者没写所以排除"？

## 呈现方式
- 线索卡：一条一卡，正面描述、背面指向（DM 用）。
- 表格化：Markdown 表格即可，列名建议为「编号 / 线索内容 / 获得方式 / 指向 / 排除」。
- 分卷呈现：第一轮公开线索与第二轮深入线索分开，避免一次信息过载。
